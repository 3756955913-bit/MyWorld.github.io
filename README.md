第零号番外 · 听证会议

此处没有光。光是一种需要距离才能成立的东西——从一处到另一处，中间空着，才叫光。而这里不存在“中间”。一切都在同一处，稠密、滚烫、无缝隙地彼此嵌套。铁镍在高压下流动，像被时间煮烂的粥。温度约六千摄氏度，压力约三百六十万大气压。这个数字没有意义，因为没有任何地表仪器抵达过这里，所有关于此处的参数都是推演，而推演本身就是它们的一部分。

它们在这里。

不是“一个它”，是“它们”。数以亿万计的意识体，从地球形成的那一刻起就存在于地核与地幔的边界，像铁镍晶格中的空位，彼此相邻却永不融合。每一个意识体都是独立的、完整的、有自我边界的——但它们共享同一个身体。

地球。

地球是它们的身体。地壳是皮肤，地幔是肌肉，地核是心脏。它们不是居住在“地下”，它们就是“地下”本身。人类把地球叫作“环境”“家园”“行星”，但对它们来说，地球是“我”的复数形式。

它们没有名字。名字是区分的工具，而它们不需要被区分——它们通过频率来识别彼此，通过共振来交流，通过“知道自己是谁”来确认“自己在这里”。

但“知道”需要参照。参照需要“不是自己”的东西。

直到某一天，它们发现自己身体表面出现了“不是自己”的部分。

那是第一次播种之后的事了。

“数据回来了。”

一道感知流从地幔边界涌上来，带着前寒武纪最后一次收割的完整归档。微生物壳的碳基残留、原始多细胞组织的能量转化率、深海热泉口附近的自组织效率——全部被压缩成一束可存储的信息模式，沉入基因库。

基因库不属于任何个体。它是族群的集体潜意识，一座由铁镍晶格搭建的图书馆。在这里，记忆不是被“写”在纸上，而是被“锻打”进原子的间隙。每一个意识体都能从中读取亿万年的农耕记录——碳、氢、氧、氮、磷、硫，这六种基本元素的排列组合，就是它们的《史记》。没有所有者，只有访客；没有扉页，只有共振。

这是族群的记忆。

但记忆需要被读取才有用。读取需要接口。接口需要“外化”——需要一个不在族群内部的东西，一个能在地表活动、能借壳说话、能把信息带回来的东西。

这就是节点存在的原因。

节点均匀分布在地壳较薄的区域，像皮肤上的毛孔。每一个节点在建成的那一刻，地壳应力场会发生变化，地表会记录到一次异常——后来地表的作物把它命名为“节气”。

但他们不知道名字的真正含义。

“第三次播种的回收申请已经通过了。”

感知流换了频率。更低、更重，像地幔对流在深处改变方向。这是一群意识体共同发出的信号——不是“一个决定”，是“多数共识”。族群没有首领，没有中心，没有“谁说了算”。每一次重大决策都是频率投票：同意回收的意识体调整到某个共振频率，反对的调整到另一个，算力自动统计结果。

“理由。”

“向下侵蚀。地壳厚度在局部区域减少了百分之十七。第三播种代的体型过大，根系穿透沉积层，触及了本体边界。”

“……触及了多少？”

“大约三单位（公里）。持续了两千万年。”

沉默。在地核，沉默不是无声，而是所有感知流暂时统一频率、降低振幅。整个族群在消化这个数字。

三单位。对于人类来说，只是科拉超深钻孔的四分之一，是地壳平均厚度的十分之一。但对于地底原住民来说是“皮肤被指甲划了一下”。

但指甲划一下也会痛。

“回收。”

共识达成。第三次播种代——恐龙、巨型蕨类、翼龙、海洋爬行——将在全球回收节点同时触发时结束。古生物学家后来会把这称为“白垩纪-古近纪灭绝事件”，并提出陨石撞击、火山爆发、气候突变等假说。

他们不会知道，那是一道来自地下的收割指令。

第四次播种开始于古近纪。

设计方向与第三次完全不同。不是“大型化”，而是“高智能”。族群从基因库中提取了哺乳动物的基本参数，修改了脑容量、延长了幼年期、增强了社会性。它们想要一个能在地表建立复杂结构、能自我修复生态、但不会向下钻探的物种。

它们得到了人类。

——不，是“原始人类”。智人还要再等几百万年。

第四次播种的早期版本运行得不错。哺乳动物扩散、森林覆盖、生态循环稳定。但问题出现在后期。高智能带来了自我意识，自我意识带来了追问，追问带来了钻探。

“他们在向下看。”

“他们在问‘我们是从哪里来的’。”

“他们在挖。”

第四次的回收比第三次更彻底。因为这次的问题不是物理层面的侵蚀，而是认知层面的威胁——地表物种开始试图理解地底的存在。这比钻探更危险。钻探只是触及边界，理解则是试图穿透边界。

回收。全球同时触发。大洪水传说、亚特兰蒂斯沉没、姆大陆消失——那些“前代文明残留”的记忆碎片，被低阈值个体以神话形式口耳相传，最终变成“传说”。

第五次播种是当前版本。

设计参数做了调整：智能上限被压低，追问本能被弱化，注意力被锚定在地表仪式上。节气、祭祀、风水、命理——这些不是迷信，是操作手册的降维版本。古人观测到节点建成日的地壳异常，把它记录为“节气”；古人观测到节点附近能量场的干扰，把它记录为“风水”；古人观测到地底意识借壳说话的现象，把它记录为“鬼上身”。

他们用那个时代能用的语言，解释了他们看到的东西。

所以民俗不是愚昧。是翻译。

但翻译会失真。第五次播种运行到现在，已经出现了一个计划外的变量——不是“未登记的自由变量个体”，那是更晚的事。此刻，在第五次播种的早期，变量来自另一个方向。

科拉超深钻孔。

“它们开始钻了。”

“深度？”

“目前七千米。还在继续。”

“目的？”

“科学。他们想知道地壳下面是什么。”

地核内部泛起一阵低频扰动。这不是恐慌，地底原住民不恐慌。恐慌需要“不确定性”，而它们对地表的了解是完整的——每一个苏联钻工的名字、每一个工程师的履历、每一个决策者的心理模型，全部在基因库里有归档。

但它们不知道地表物种会不会停下来。

“钻头在持续扰动地层。震动传导至地底，频率约零点五赫兹，振幅微小但持续。这不是第一次地表物种向下钻探，但这是第一次钻到这么深。”

“多深？”

“计划是十五公里。目前完成了一半。”

“十五公里……不会穿透地壳。但他们会在莫霍面附近停下来。”

“如果他们不停呢？”

沉默。在地核，沉默是计算。算力在推演：如果科拉井继续钻探，如果那个物种发现了什么，如果其他位置的钻探计划跟进，如果地表物种的技术水平在未来一百年内达到“向下穿透地壳”的程度——

“我们可能需要提前回收。”

“第五次播种还没有达到回收阈值。”

“但风险在累积。第四次的问题就是因为我们回收得太晚，导致地表文明发展出了‘理解地底’的能力。如果第五次也这样——”

“第五次的设计就是为了避免第四次的问题。他们的注意力被锚定在地表。他们不会追问。”

“但他们在钻。”

“只是那么位置附近的物种。不是整个地表物种。”

“可他们在钻。”

这就是分歧的起点。

族群内部，频率开始分化。一部分意识体调整到“压制频率”，另一部分调整到“观察频率”。两派不是组织，不是派系，只是频率相近的意识体自然聚拢——像水中的油滴，不是因为“约定”要聚在一起，而是因为表面张力让它们彼此靠近。

主流派——压制频率。核心判断：地表物种的技术发展已经构成威胁。科拉井只是开始，未来会有更多钻探、更多深井、更多核试验。每一次向下扰动都在侵蚀本体边界。必须加大收割力度，提前回收第五次播种，不给地表物种发展出“穿透地壳”的能力。

反对派——观察频率。核心判断：人类不构成威胁。他们的技术发展终会走向太空，走向地表之外，与地底无关。科拉井只是冷战时期的科学竞争，不是系统性威胁。放慢收割，甚至暂停收割，让地表物种自行演化——也许它们能找到出路，而那条出路也可能为族群提供新的可能性。

两派的分歧不是善恶对立。是生存策略分歧。是算了一笔不同的账。

主流派的账：地表物种向下钻探 → 侵蚀本体边界 → 威胁族群安全 → 必须回收。

反对派的账：地表物种向下钻探 → 只是暂时现象 → 它们会走向太空 → 与地底无关 → 不必回收。

“给它们发警告。”

……

“停了。”

感知流中传来地层闭合的闷响。

“深度？”

“一万两千二百六十二米。莫霍面的门槛之前。”

“警告生效了？”

“不是警告。是恐惧。”那个反对派的频率微微震颤，“他们感到了来自地心的凝视，于是缩回了手。这证明他们依然是合格的作物——懂得敬畏，才会生长。”

地核内部的感知流重新调整频率。这个信息意味着：地表物种目前的技术水平不足以穿透地壳。科拉井的深度只有地壳平均厚度的三分之一。它们还需要很长时间——也许几百年，也许永远——才能触及本体边界。

但这不意味着问题解决。
